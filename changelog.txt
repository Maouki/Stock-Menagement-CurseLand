[2026-08-24] v1.0.0 — เริ่มต้นระบบครั้งแรก
────────────────────────────────────────────────────────────────────────────────
  ใหม่  app.py
       - สร้าง Flask backend พร้อม REST API
       - GET  /api/sheets        — ดึงรายชื่อแผ่นงานทั้งหมดจาก Excel
       - GET  /api/items         — โหลดรายการสินค้าพร้อมโครงสร้างหมวดหมู่
       - POST /api/items         — เพิ่มสินค้าใหม่และบันทึกลง Excel
       - PUT  /api/items/<row>   — แก้ไขข้อมูลสินค้าใน Excel
       - DELETE /api/items/<row> — ลบแถวสินค้าออกจาก Excel
       - GET  /api/stats         — สรุปจำนวน (ทั้งหมด / สต๊อกต่ำ / หมด / ใกล้หมดอายุ)
       - อ่านไฟล์ Excel: สต๊อกสินค้า ปาร์คอิน.xlsx
         คอลัมน์: ลำดับ | บาร์โค้ด | ประเภทหลัก | ประเภทย่อย | ชื่อสินค้า
                  Brand | Lab | Lot | วันหมดอายุ | สต๊อกตั้งต้น | สต๊อกคงเหลือ
         ข้อมูลเริ่มจากแถวที่ 3 (แถว 1 = หัวตาราง, แถว 2 = ป้ายหมวดหมู่)

  ใหม่  templates/index.html
       - หน้าเดียว (Single-page) มี Sidebar สีเข้มและพื้นที่เนื้อหาหลัก
       - Dropdown เลือกแผ่นงาน Excel
       - การ์ดสรุปสถิติ (ทั้งหมด / สต๊อกต่ำ / หมดสต๊อก / ใกล้หมดอายุ)
       - แถบหมวดหมู่ฝั่งซ้าย (ประเภทหลัก → ประเภทย่อย) สำหรับกรองข้อมูล
       - ช่องค้นหา (ค้นได้จาก ชื่อ / บาร์โค้ด / Brand / Lot / หมวดหมู่)
       - แท็บกรองด่วน: ทั้งหมด / สต๊อกต่ำ ≤10 / หมดสต๊อก / ใกล้หมดอายุ
       - เรียงลำดับตาม: ลำดับ / ชื่อสินค้า / สต๊อกคงเหลือ / วันหมดอายุ
       - ป้ายสต๊อกแสดงสีตามสถานะ (เขียว / เหลือง / แดง)
       - ฟอร์ม เพิ่ม / แก้ไข แบบ Modal พร้อม Autocomplete หมวดหมู่
       - กล่องยืนยันก่อนลบ
       - Toast แจ้งผลลัพธ์ (สำเร็จ / ผิดพลาด)

  ใหม่  static/style.css
       - CSS แบบกำหนดเองโดยใช้ฟอนต์ Sarabun (Google Fonts)
       - Sidebar พับเก็บได้บนมือถือ (Responsive)

  ใหม่  static/app.js
       - JavaScript ล้วน ไม่ใช้ Framework
       - กรองและเรียงลำดับฝั่ง Client (ไม่ต้องโหลดข้อมูลซ้ำจากเซิร์ฟเวอร์)
       - ใช้ fetch() สำหรับการทำงาน CRUD ทั้งหมด

  ใหม่  start.bat
       - ไฟล์ช่วยเปิดระบบ: เริ่ม Flask และเปิดเบราว์เซอร์อัตโนมัติ

[2026-08-24] v1.1.0 — แก้ไขข้อผิดพลาดการลบและแก้ไขสินค้า
────────────────────────────────────────────────────────────────────────────────
  แก้ไข  app.py
       - เปลี่ยน URL จาก PUT/DELETE /api/items/<sheet>/<row>
         เป็น /api/items/<row>?sheet=... (ส่ง sheet เป็น Query String)
         สาเหตุ: ชื่อแผ่นงานภาษาไทยใน URL Path ทำให้ Flask จับเส้นทางผิด
                 และส่ง HTML Error กลับแทน JSON ทำให้เบราว์เซอร์แสดงข้อผิดพลาด
                 "Unexpected token '<'"
       - เพิ่ม @app.errorhandler(Exception) ระดับ Global เพื่อให้ทุกข้อผิดพลาด
         ส่ง JSON {success: false, error: "..."} แทนหน้า HTML
       - เพิ่มการจัดการ PermissionError พร้อมข้อความภาษาไทย:
         "ไฟล์ Excel ถูกเปิดอยู่ กรุณาปิด Excel แล้วลองใหม่"
       - แยก save_excel_safe(wb) เป็นฟังก์ชันกลางสำหรับทุกการบันทึก

  แก้ไข  static/app.js
       - อัปเดต URL ของ fetch() สำหรับ PUT และ DELETE ให้ส่ง sheet เป็น Query String
       - Toast แสดงข้อความ result.error จากเซิร์ฟเวอร์แทนข้อความทั่วไป

[2026-08-24] v1.2.0 — ปรับฟอนต์ให้สม่ำเสมอทั่วทั้งไฟล์ Excel
────────────────────────────────────────────────────────────────────────────────
  เปลี่ยนแปลง  app.py
       - เพิ่มค่าคงที่ DATA_FONT = Font(name='Sarabun', size=16)
       - เพิ่มฟังก์ชัน set_row_font(ws, row_idx): ใช้ DATA_FONT กับคอลัมน์ A–K
       - save_item_to_excel() เรียก set_row_font() หลังบันทึกค่าทุกครั้ง
       - add_item_to_excel() เรียก set_row_font() หลังบันทึกค่าทุกครั้ง
       - เพิ่ม POST /api/normalize-fonts: สแกนทุก Cell ข้อมูล (แถว 3+, คอลัมน์ A–K)
         ในทุกแผ่นงาน และแก้ไข Cell ที่ฟอนต์ไม่ตรง DATA_FONT
         ส่งผลลัพธ์ { cells_fixed: N } กลับ
       - รันแก้ไขครั้งเดียวเพื่อปรับ 718 Cell ในไฟล์ที่มีอยู่
         (เดิมใช้ Sarabun 17/18, Tahoma 16/17, Arial 10 — ปัจจุบันเป็น Sarabun 16 ทั้งหมด)
       - แถวหัวตาราง (แถว 1–2) ไม่ถูกเปลี่ยนแปลง
